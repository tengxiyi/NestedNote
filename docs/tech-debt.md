## 登记规范

1. 发现债务 → 立即开一条记录，不要等到"以后统一整理"。
2. 每条债务必须在对应代码处留一行引用注释，格式：`// TECH-DEBT(#12): 见 docs/tech-debt.md`
3. 每次阶段 Gate 评审时逐条过一遍：偿还、延期（写新日期）、或升级为正式任务。
4. **禁止**无限延期：同一债务延期 3 次以上必须排入当前阶段。
